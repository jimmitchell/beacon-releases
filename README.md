# Beacon

A free, Raycast-style launcher for macOS 26 and later: apps, a calculator, window management, file and emoji search, clipboard history, snippets, quicklinks and script commands.

**Download:** grab the DMG from the [latest release](https://github.com/jimmitchell/beacon-releases/releases/latest), open it and drag Beacon to Applications. Beacon updates itself from then on.

This repository holds the release downloads and `appcast.xml`, the feed Beacon checks for updates.
